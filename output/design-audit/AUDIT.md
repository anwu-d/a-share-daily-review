# 设计审计 · A股每日复盘结论页

> 2026-09-18 · combined audit（UX + 无障碍）· 无头 Chrome 1440×900 与 390×844
> 证据：本次现场捕获的 14 张截图 + DOM / 计算样式 / 键盘探针。截图保存在 `output/design-audit/`。
> 说明：本机**没有**已保存的 Product Design 用户上下文（`user-context.md` 不存在），因此审计只以现场截图为准。

---

## 1. 审计范围

- **产品面**：`index.html` — A 股每日复盘「结论版」页面（复盘日 2026-09-16）。
- **路径**：从封面读到「来源与方法」的完整阅读流（11 屏），外加两个交互面 —— 指标条 drill 弹窗、封面连板图 drill 弹窗。
- **模式**：combined（UX + accessibility）。
- **不在本次证据范围内**：引擎与数据管线的工程设计（见第 9 节，已单独标注）。

## 2. 用户目标与无障碍对象

页面的读者是一个用它做**次日操作决策**的人：他要快速知道「今天市场什么状态、明天做什么、不做什么、哪些标的要盯、这些数字从哪来」。无障碍对象是同一个人在键盘操作或读屏软件下能否完成同样的阅读。

## 4. 优势

这一页最扎实的地方是**数字的可追溯性**，在同类自制看板里少见：

- 每个板块下面都有带日期的 `Source · …` 行（`03`、`04`…）；来源板块还有一整套证据分级与来源类别徽章（`11`）。
- drill 弹窗把出处写进弹窗本身（`12`：`Source · 本地 qlib + 东财 · 2026-09-16`；`13`：`东财涨停池/炸板池 API · 2026-09-16（K1/K2/K3）`）。
- 形态信号板块把**评分公式直接写在页面上**（`09`：`评分 = 40 + 20×命中组合数 + 800×组合历史后5日均涨幅…二者不同源`）——这是把方法透明度当成交付物，而不是藏起来。

结构面也干净：

- 标题层级正确：一个 H1 → 10 个 H2，无跳级；`lang="zh-CN"` 已设。
- 11 张数据表**全部**有 `<thead>`。
- 吸顶导航是真正的 `<a>`，点击区域 45×46px，**满足 44×44 的目标尺寸要求**。
- 主要文字对比度优秀：H2 17.4:1、导语 7.6:1、表格正文 17.4:1。
- CSS 里有 `prefers-reduced-motion` 分支（入场动画在减弱动效偏好下直接显示）。
- 空态现在会说话：表2 显示「自动模式未生成隔夜套利条件单（可人工补充 plan2）」（`06`），自选池口径文案也不再重复（`08`）。

## 5. UX 风险

**R1 · 内部代号泄漏到读者文案里（高）**
板块 8 的 eyebrow 是 `PATTERNCOMBOGATE`（`09`）——这是算法类名；来源板块写「完整推演见 Markdown 报告（**Prompt v4.14**）」（`11`）；表2 空态写「（可人工补充 **plan2**）」（`06`）；龙头 dek 里有「（具体标的一律见下表，由引擎按当日数据生成。）」（`05`）。读者在看的是引擎的变量名，不是给他的结论。

**R2 · 同一个板块有三个名字（高）**
导航「风险」/ eyebrow「特殊提醒」/ 标题「半导体高潮次日分化」；导航「股池」/ eyebrow「自建股池」/ 标题「自选池」；导航「形态」/ eyebrow「PATTERNCOMBOGATE」/ 标题「形态组合信号」。跳转用一套词、阅读时是另一套，读者每次都要重新对位（`07`/`08`/`09`）。

**R3 · 结论列全是同一句话（高）**
自选池 10 行的「结论」列，除了把方向词换掉以外**完全相同**（`08`）：「自选 PCB/硬件；今日未涨停，按技术位跟踪」×2、×2、×3… 状态列也全是「观察」。龙头表 5 行的结论列全是「接力风险高，只作温度计」（`05`）。表格看起来像分析，实际没有区分任何一只票。

**R4 · 数字量级不可信（高，需先查单位）**
龙头表封单写「4336.90 亿 / 6803.33 亿 / 15622.26 亿」（`05`），明日计划表写「封单 21491.05 亿」（`06`）。一只 2 板股 1.5 万亿封单不合常理——更像是单位错了（元被当成亿）。只要这个错了，页面上所有封单数字都不能用。

**R5 · 新闻板块重复且离题（高）**
`10` 里每条快讯的标题和摘要**是同一段话**——因为这些条目没有独立摘要，前端把标题再 slice 一遍贴上去。同时政策/外围栏前 6 条全是**加拿大央行会议纪要**，对 A 股短线复盘几乎没有决策价值；而且时间戳是 **09-17**，与页头「数据截至 2026-09-16」冲突。

**R6 · 空表仍渲染完整表头 + 一大片空白（中）**
表2 有 6 列表头 + 一行灰字占位，占了约 130px 高度（`06`），读起来像表格坏了而不是「今天没有」。

**R7 · 截断文案没有展开入口（中）**
速览的「不做什么：…缩量市中军主升追高 …」以省略号结束，没有展开控件（`02`）。读者看不到剩下的「不做什么」，而这恰恰是最该看完的一段。

**R8 · 封面图表可读性弱（中）**
`01` 里「1 板」台阶是一个大的空心矩形，方块浮在它上方；炸板簇（左侧虚线小方块）在这个尺寸下像乱码；右侧「⚠监管警示」与「闽东电力 · 6 板」两个标签**互相叠压**。窄屏 `14` 下图表直接缩成不可读，且说明文字写「右侧画布」而画布实际在**下方**——文案已经与事实不符。

**R9 · drill 弹窗遮住它要解释的东西（中）**
`13` 的弹窗压在 77 个首板方块上；`12` 的弹窗压住「一句话定性：修复日」标题。深蓝底配纯白页面，看起来像另一个产品。

**R10 · 「昨日 —（未接缓存）」（低）**
`03` 右栏这行字诚实，但读起来像数据故障。缺数据的表达需要更平静。

## 6. 无障碍风险

**A1 · 可点击区域只能用鼠标（高）**
指标条 6 个格子和封面连板图都能点开 drill，但它们分别是 `DIV` 和 `CANVAS`，`tabindex`/`role`/`aria-label` **全是 null**（DOM 探针实测）。键盘用户和读屏用户完全够不到 drill 里的内容——而 drill 恰恰是封面图表**唯一**的文字替代。

**A2 · 弹窗不能用 Esc 关闭（高）**
实测 `drillClosedByEsc = false`。弹窗也没有 `role="dialog"`、没有焦点移入、关闭按钮「✕」`aria-label` 为 null（图标按钮无可访问名称）。

**A3 · 两张图是纯 canvas（高）**
封面连板图与五维分解图都是 canvas 绘制。五维图**有** DOM 文字标题（「五维合计 83 分 / 满分 100：最稳 市场广度 20/20，扣分最多 量能风偏 14/20」）——这是部分缓解；封面图的唯一文字等价物是画布下方一小行灰字说明，而 drill 又是鼠标专属。

**A4 · 两处灰色达不到 AA 对比度（中）**
- `.muted`：rgb(133,149,166) on 白 = **3.07:1**，14px —— AA 要求 4.5:1
- `.colophon`（页脚）：同色 on #F7F9FC = **2.91:1**，10.5px —— 更低

主内容对比度很好，但这两个被系统性地用在次要信息上，恰好是读者需要确认数据出处的地方（页脚 colophon 写的就是口径声明）。

**A5 · 11 张表都没有 `<caption>`（低）**
读屏用户用表格导航时，只能靠前面的标题来猜这张表在讲什么。

**A6 · 焦点环是浏览器默认（低）**
`outline: 1px auto`，在信息密度这么高的页面上很弱；CSS 里没有自定义 `:focus-visible`。

**A7 · 锚点偏移靠巧合而非设计（低）**
`scroll-padding-top: auto`、`scroll-margin-top: 0px`。今天能用是因为各板块自带约 89px 顶部内边距 > 50px 导航高度。任何改内边距的动作都会让标题被吸顶导航盖住——这是脆弱的，不是设计出来的。

## 7. 机会点（按投入产出排序）

1. **命名统一**：每个板块只留一个正名，导航 / eyebrow / H2 三处同一来源。这是零成本、见效最大的一项。
2. **清掉内部代号**：`PATTERNCOMBOGATE`、`Prompt v4.14`、`plan2`、R 系列编号移到可折叠的「技术细节」里。
3. **补单位测试**：先确认封单是「亿」还是「元」，再决定表格怎么显示。数字不可信时，其它设计优化都没有意义。
4. **让结论列变成真结论**：区分不了就删列；能区分就把每只票的具体触发条件放进来。
5. **drill 做成真对话框**：`role="dialog"`、焦点移入、Esc 关闭、✕ 加 `aria-label`、位置改为不遮挡触发物。
6. **canvas 补文字替代**：给两张图加 `aria-label` + 视觉隐藏的文字表；把指标格子改成 `<button>`。
7. **两个灰色 token 提到 ≥4.5:1**。
8. **新闻去重**：没有独立摘要就不渲染摘要行；同主题连续条目合并；时间戳与「数据截至」对齐。
9. **封面图表重画**：让「阶梯」真的从左到右上升，或者改名；窄屏改成纵向堆叠而不是等比压缩；说明文字改为中性的「下方画布」。
10. **空表**：无数据时去掉表头行，占位文案横跨整表。

## 8. 证据局限

- 只在**无头 Chrome** 的 1440×900 与 390×844 两个视口下取证；没有真机、没有触屏、没有跑读屏软件。
- 对比度是从**本次渲染的计算样式**算出来的，没有采样 hover / focus / visited 等状态。
- 键盘行为只实测了「导航链接可聚焦」与「Esc 关闭弹窗」两件事；**没有做完整 tab 顺序走查**。
- `prefers-reduced-motion` 在 CSS 里存在，但**没有**在该偏好实际生效时做视觉确认。
- 页面数据来自预先生成的 `data.js`，因此**没有**走到数据缺失 / 网络失败的极端态（当前数据本身有缺失字段，但那是数据缺失不是加载失败）。
- **不声称任何 WCAG 合规结论**——截图加少量 DOM 探针不足以支撑合规判定。

## 9. 引擎与架构观察（非截图证据）

以下不是本次审计的截图证据，来自代码阅读，单独列出以免与上面的发现混淆：

1. **章节命名三处各自为政**——导航标签在 HTML 里写死、eyebrow 在 HTML 里写死、H2 又被 JS 按数据覆写。同一概念没有单一来源，所以 R2 是结构性的，不是文案笔误。
2. **表格结论列的模板化**——结论列之所以全一样，是因为数据模型里根本没存「每只票的具体结论」，模板只能插常量。UI 的问题在数据契约上。
3. **封单单位**疑似在取数层（`eastmoney.py` 的 `fund` 字段除以 1e4）就已定错，值得用一只已知股票做单元测试。
4. **新闻摘要回退**——摘要字段为空时前端回退成标题再截断，是显示层一行逻辑的问题；更该修的是数据层不返回空摘要。
5. **页面没有加载/错误/空的契约**——它假定 `data.js` 永远完整。任何一次引擎失败都会让整页出现 `—` 而没有任何提示。
6. **可借鉴的先例**：正在进行中的转型股模块已经采用了「覆盖率横幅 + 未命中清单 + 需人工标记」的诚实降级模式。其它板块缺少的正是这个——尤其是自选池和龙头表，它们现在的表现形式（假结论）比诚实的空态更糟。

## 总体判断

这一页的**可信度基础设施**（来源登记、证据分级、公式透明、drill 带出处）是它最强的部分，已经比大多数自制看板严谨。真正的问题集中在三处：**内部代号泄漏到读者文案**、**表格列在说同一句话**、**数字量级可疑**。第三点必须先查——单位错了的话，读者在信任一个错的数字。

无障碍侧的主要缺口不是配色，而是**两张 canvas 图和 6 个指标格完全在键盘/读屏之外**，弹窗也没有对话框语义。这些是结构性的，改起来不复杂。
