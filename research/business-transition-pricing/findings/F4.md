## Dead ends

- **DuckDuckGo HTML 搜索在本机完全不可达**：`https://html.duckduckgo.com/html/?q=...` 经 webfetch 报 `Transport error`，经 `requests` 报 `ConnectTimeout ... html.duckduckgo.com:443`（2 次 webfetch + 1 次 requests 均失败）。因此未能执行"以搜索为主"的路径，改为直接定位一手接口与权威源码；Bing 可达（200，95KB）但未产出比一手接口更有价值的契约信息。
- **雪球（雪球）一致预期无免登录路径**：`https://stock.xueqiu.com/v5/stock/quote.json?symbol=SZ002708` 返回 HTTP 400 `{"error_code":"400016","error_description":"遇到错误，请刷新页面或者重新登录帐号后再试"}`；`/v5/stock/forecast.json` 返回 HTTP 403（openresty）。先访问 `https://xueqiu.com/` 仅拿到 `acw_tc` cookie，不足以通过校验——**需要登录态 token，不适合本地无人值守模块**。
- `https://datacenter-web.eastmoney.com/api/data/v1/get?reportName=RPT_RESEARCHREPORT_STOCK` 报 `{"success":false,"message":"报表配置不存在,RPT_RESEARCHREPORT_STOCK","code":9501}`——该报表名不存在，勿用。
- `report/list` 的 `qType=3/4/5/6/7` 恒为 0 条（东方财富前端另有「券商晨会/宏观研究/新股研报」栏目，但该接口不支持）；`rating=买入` 过滤返回 0 条；`code` 不带 `qType` 静默返回空。
- `akshare/stock_feature/stock_profit_forecast_em.py` 等 4 个猜测路径均 404，实际路径为 `akshare/stock_fundamental/stock_profit_forecast_em.py`；GitHub code search API 未授权（401），无法用它定位文件。
- 未找到东方财富官方的 API 契约文档（该接口无公开文档），亦未找到披露官方限流配额的页面；限流结论只能来自自测压测。

## Suggested follow-ups

- `rating` 参数的确切取值（是否需传 `emRatingCode` 如 `007`）与 `ratingChange=4` 的语义，可用更多代码样本 + 对比前端筛选器请求复现确认。
- `RPT_WEB_RESPREDICT` 的 `EPS_LASTMONTHS` 是否提供「更多历史月份」的预期快照（当前仅见 1 个滞后月）；若只有 1 个月，则「预期修正趋势」需靠本地逐日持久化自建，值得验证是否有按月份序列的报表名。
- 东方财富一致预期数与同花顺一致预期数的口径差异（实测 002708 为 0.3533 vs 0.40）——在把「卖方偏离度」做成打分前，需要确定以哪一源为基准，或如何对齐机构样本集。
